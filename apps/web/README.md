# `apps/web` — retired

This directory previously held a Next.js step-wizard UI. It is **not** the product frontend.

**Product UI:** Vite agent shell at the repo root (`src/`, `npm run dev` → [http://localhost:5173](http://localhost:5173)).

**Product API:** companion BFF in `apps/agent` (`uvicorn` → `:8000`).

Do not run or restore a Next app here for day-to-day development. See the root [README.md](../../README.md) for how to run the shell + agent.
